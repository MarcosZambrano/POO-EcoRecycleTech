# POO-EcoRecycleTech

Sistema de gestión para planta de clasificación automatizada de residuos (EcoRecycle Tech SA).

## Autor
- Nombre: Marcos Daniel Zambrano Díaz
- Asignatura: Programación Orientada a Objetos
- Institución: UTAMED

## Arquitectura
Proyecto desarrollado bajo el patrón Modelo-Vista-Controlador (MVC), con las siguientes carpetas:
- `src/main/java/modelo`: lógica de negocio (Residuos, Contenedores, Factory)
- `src/main/java/vista`: interfaz gráfica en Java Swing
- `src/main/java/controlador`: controladores que conectan modelo y vista
